# Task 1 - Student Grade Calculator

A console-based Java application that calculates a student's total marks, average marks, and final letter grade based on marks entered for five subjects.

## Features

* Accept student name and marks for 5 subjects
* Calculate total marks
* Calculate average marks
* Assign a letter grade based on the average
* Display a formatted summary of results

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Arrays
* Scanner for user input

## Project Structure

* Main.java
* Student.java
* GradeCalculator.java
* README.md

## How to Run

### Prerequisites

* Java Development Kit (JDK) 8 or higher

### Compile the Program

Open a terminal in the project folder and run:

```bash
javac Main.java Student.java GradeCalculator.java
```

### Run the Program

```bash
java Main
```
