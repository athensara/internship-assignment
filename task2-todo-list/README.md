# Task 2 - Todo List

A console-based To-Do List application written in Java that allows users to manage tasks through a menu-driven interface.

## Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Handle invalid user input gracefully
* Continue running until the user chooses to exit

## Technologies Used

* Java
* ArrayList
* Object-Oriented Programming (OOP)

## Project Structure

* Main.java
* Task.java
* README.md

## How to Run

### Prerequisites

* Java Development Kit (JDK) 8 or higher installed
* A terminal, Command Prompt, VS Code, VS Codium, or any Java IDE

### Compile the Program

Open a terminal in the project directory and run:

```bash
javac Main.java Task.java
```

### Run the Program

```bash
java Main
```
